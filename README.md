# 🌟 theEJC Repository

이 저장소는 **EJC 프로그램 수행 중 제작된 자료들**을 정리하고 공유하기 위한 공간입니다.

---

## 📘 프로젝트 개요
EJC(ERP Junior Consultant) 프로그램은 ERP 및 AI 서비스 기획·개발 역량을 함께 기르는 실무형 교육 과정입니다. 본 저장소에서는 프로젝트별 산출물, 학습 정리, 및 실습 결과를 체계적으로 관리합니다.
